管道连接挑战：帮助动物通过连接管道到达对岸。

图像布局：
- 左侧（x: 0-350）：管道拼图区域，可能有1个或多个缺口需要填补
- 右侧（x: 375-500）：可拖动的管道碎片，每个碎片显示为独立图标

分析步骤：
1. 观察左侧管道拼图，找到所有缺口位置和所需管道类型
   - 缺口形状可能是：直管、90°弯管、三通、四通
   - 注意缺口的朝向和连接口方向
   - 数一下需要填补几个缺口
2. 查看右侧的候选管道碎片（通常在x≈436位置）
   - 比较每个碎片的形状、朝向、连接口数量
3. 为每个缺口选择匹配的碎片
   - 有些挑战只需要1个碎片
   - 有些挑战需要2个或更多碎片填补多个缺口
   - 不匹配的碎片留在原地不要动
4. 从每个选中碎片的中心拖到对应缺口的中心

重要：
- 右侧的管道碎片是拖动起点（source）
- 左侧的缺口是放置目标（destination）
- 可能需要旋转碎片才能正确匹配
- 根据拼图需要拖动1个或多个匹配的碎片
- 使用网格坐标精确放置到缺口中心

输出要求：
- paths: 数组，每个元素包含一次拖动
  - start_point: 选中碎片的中心坐标
  - end_point: 对应缺口的中心坐标
